# 倉吉クエスト

倉吉市内の10スポットを巡り、クイズに正解してキャラクター・ポイント・アイテムを集める位置情報Webアプリです。

## 主な機能

- 現在地を地図上に表示
- 倉吉市内の10スポットを表示
- スポットの50m以内でクイズを表示
- 正解すると100XP・100ポイント・アイテムを獲得
- キャラクター図鑑とレベルアップ
- iPhoneカメラを使った簡易AR表示
- 進行状況を端末内に保存

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します。
2. このZIPを解凍し、`index.html`、`.nojekyll`、`README.md`をリポジトリ直下へアップロードします。
3. GitHubのリポジトリで `Settings` → `Pages` を開きます。
4. `Build and deployment` のSourceを `Deploy from a branch` にします。
5. Branchを `main`、フォルダを `/ (root)` にして `Save` を押します。
6. 数分後に表示されるURLをiPhoneで開きます。

## iPhoneでの利用

- 位置情報とカメラの利用は「許可」を選んでください。
- GPSには誤差があるため、実地テスト後にスポット座標や判定距離を調整してください。
- AR機能はカメラ映像にキャラクターを重ねるWeb版の簡易ARです。

## 注意

地図データはOpenStreetMapを利用しています。位置情報・獲得データはサーバーへ送信せず、利用端末内に保存します。
